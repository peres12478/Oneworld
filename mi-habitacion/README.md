# Mi habitación — contenido personal sin API

**Archivo para personalizar tu habitación:** `js/datos-personales.js`.

- `github.nombre`: **único nombre** que aparecerá en la ficha de GitHub.
- `github.url`: **único enlace**, a tu perfil o directamente a tus repositorios. Ejemplo: `https://github.com/tu-usuario?tab=repositories`.
- `pasiones.introduccion`: presentación de tus pasiones.
- `pasiones.intereses`: lista opcional de intereses con `nombre` y `descripcion`.
- `sobreMi.nombre`: nombre para tu presentación.
- `sobreMi.fechaNacimiento`: fecha opcional AAAA-MM-DD.
- `sobreMi.presentacion`: texto «Quién soy».

La ficha **Mi GitHub** solo muestra el nombre y un enlace. No hay proyectos destacados, tarjetas de proyectos ni lista de repositorios local. El enlace abre GitHub en otra pestaña.

**No uses `proyectos`, `github.usuario` ni `github.introduccion`: esos campos se retiraron.** No cambies los HTML o las animaciones para actualizar tus datos.

Si publicas el sitio, lo que escribas en este archivo será público: evita datos privados.

Esta habitación es personal y **no consulta APIs**.
